
# Data

This project uses historical used-car listing data from the CarDekho dataset and state-level vehicle registration data from the Government of India OGD/Vahan source.

- `cardekho_cleaned_for_project.csv` — cleaned used-car analysis dataset
- `vahan_snapshot_with_brand_match.csv` — state-level registration snapshot with maker matching

The expansion score is a directional supply-potential proxy, not a forecast of future used-car inventory.
